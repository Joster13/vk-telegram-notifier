# VK Notify — серверный вариант через Gmail (Bothost)

Исправление разбора Gmail, ограничения и безопасное обновление с откатом:
[PARSER_ROLLOUT.md](PARSER_ROLLOUT.md). Все автономные тесты: `python -m unittest discover -v`.

Используйте **gmail_bot.py** в качестве главного файла на Bothost (Python 3.11).
Этот режим читает уведомления, которые VK прислал в Gmail, а не личные
сообщения напрямую из API ВКонтакте. Уведомления могут приходить с задержкой;
вложения, отсутствующие в письме, не пересылаются.

Переменные окружения Bothost:
- TG_BOT_TOKEN — токен Telegram-бота (или BOT_TOKEN от хостинга).
- TG_CHAT_ID — ID вашего приватного чата с ботом.
- GMAIL_ADDRESS — адрес Gmail для уведомлений VK.
- GMAIL_APP_PASSWORD — пароль приложения Google (не обычный пароль аккаунта).
- GMAIL_IMAP_HOST — imap.gmail.com.
- GMAIL_SENDER — admin@notify.vk.com.
- POLL_SECONDS — 60.

Никаких токенов и паролей в GitHub. Репозиторий может оставаться публичным.
После первого старта отправьте боту /test и /status, а затем дождитесь
**нового** письма от ВКонтакте. Существующую историю бот по умолчанию пропускает.

После изменения кода или переменных перезапустите бот через Bothost.
Одна почта Gmail и один Telegram-бот должны обслуживаться только одним
работающим экземпляром этого скрипта.

# VK → Telegram: уведомления о личных сообщениях

Локальный Python-процесс, который слушает **User Long Poll** вашей личной страницы ВКонтакте, получает полное входящее сообщение через `messages.getById` и пересылает содержимое в выбранный личный Telegram-чат.

## ВАЖНО о VK API

Доступ к API **личных сообщений** для сторонних VK-приложений ограничен. Требуется **разрешённый пользовательский токен** с правом читать сообщения, полученный через допустимую VK процедуру авторизации. **Токен сообщества** позволяет читать сообщения *сообществу*, но не сообщения, приходящие на вашу личную страницу. В этом проекте нет обходов ограничений, сбора пароля, cookie или токенов сторонних приложений.

Если вызов `messages.getLongPollServer` отвечает `Access denied`/`Permission denied`, с обычным VK-токеном этот вариант не заработает. Потребуется согласованный доступ VK либо альтернативная схема через уведомления устройства (с ограничениями по медиа).

## Возможности

- Входящие личные сообщения, от сообщества, из бесед (если этот аккаунт видит их через API).
- Имя отправителя из VK, название беседы (если доступно), время по Москве, текст любой длины.
- Фото, стикер как изображение, голосовые, документы, GIF и прямые видеофайлы, если их выдаёт API.
- Видео без прямого MP4, закрытые или неподдерживаемые вложения — кликабельные ссылки, иногда превью.
- Прямая ссылка `vk.com/im?sel=...&msgid=...` и кнопка «Ответить в ВК ↗». В некоторых версиях клиента VK выделение **конкретного сообщения** по `msgid` может не поддерживаться, но переход в диалог остаётся.
- Защита от повторов после перезапуска (SQLite, срок хранения ID 30 дней), переподключение Long Poll, учёт лимитов Telegram. При сбое сети единичные события могут быть пропущены или продублированы; строгая гарантия доставки не реализована.
- Бот не принимает команды от сторонних пользователей; отправляет только в `TG_CHAT_ID`. Открытые сообщения в Telegram **не шифруются сквозным образом**, не используйте для особо чувствительных переписок.

## Настройка на Windows

1. Установите **Python 3.10 или новее** с галочкой `Add Python to PATH`.
2. Создайте Telegram-бота в [@BotFather](https://t.me/BotFather): `/newbot`. Скопируйте токен.
3. Распакуйте ZIP и дважды нажмите `setup_windows.bat`. Будет создана виртуальная среда, установлены зависимости и создан `.env`.
4. Откройте `.env` в Блокноте, вставьте токен от BotFather в `TG_BOT_TOKEN`.
5. Напишите своему боту в Telegram команду `/start`.
6. В PowerShell из папки проекта выполните:

```powershell
.\.venv\Scripts\python.exe chat_id.py
```

7. Вставьте показанный **ID именно вашего** чата в `.env` как `TG_CHAT_ID`.
8. Вставьте **пользовательский** VK-токен с реально предоставленным правом `messages` в `VK_TOKEN`.
9. Дважды нажмите `start_windows.bat` (или выполните `.\.venv\Scripts\python.exe bot.py`).

При первом запуске бот сообщает о запуске. Если есть доступ к `messages.getLongPollServer`, новые входящие сообщения VK будут появляться в Telegram. Старую историю он не отправляет.

## Где получить VK_TOKEN

Вход в обычный аккаунт VK **не создаёт автоматически** API-токен для чтения личной переписки.

1. Откройте платформу разработчиков VK: https://dev.vk.com/ (приложения и настройки доступа).
2. Если у вас **уже есть приложение**, которому VK разрешил пользовательский API-доступ `messages`, используйте **официальную авторизацию пользователя** этого приложения с разрешением читать сообщения. Полученное значение — `VK_TOKEN`.
3. Если приложения нет либо в перечне прав отсутствует `messages`, обычное создание VK ID-приложения **не гарантирует**, что VK выдаст нужный токен. Обратитесь к документации и поддержке платформы VK за доступом. Мы не предлагаем извлекать cookie/пароли или чужие служебные токены.
4. При старте бот проверяет `messages.getLongPollServer`. Если VK отвечает ошибкой 7/15/20, это не ошибка Telegram — без соответствующих разрешений мониторинг личной переписки недоступен.

**Важно:** ключ доступа сообщества (из настроек сообщества → Работа с API) **не подходит** для чтения личных входящих вашей страницы VK. Для сообщений, адресованных вашему собственному сообществу, потребуется другая версия бота на Group Long Poll/Callback API.

## 24/7 на VPS / Linux

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

Этот вариант не подтягивает историю за время выключенного процесса: слушаются только новые события, полученные во время работы. Для постоянных уведомлений нужен непрерывный запуск.

Для фонового запуска создайте systemd unit с `WorkingDirectory` на эту папку и `ExecStart=/.../vk_telegram_notifier/.venv/bin/python /.../vk_telegram_notifier/bot.py`, настройте `Restart=always` и `RestartSec=10`. Не запускайте две копии на один VK аккаунт (дубли уведомлений).

## Как работает пересылка вложений

| VK вложение | Telegram |
| --- | --- |
| Текст | Сообщение с кнопкой |
| Фото | Фотография, иначе ссылка |
| Стикер | Статичная картинка, анимированная форма не гарантируется |
| GIF | Анимация, иначе ссылка |
| Голосовое | Voice или Audio, иначе ссылка |
| Документ | Файл, иначе ссылка |
| Видео | Видеофайл при наличии MP4, иначе превью + ссылка |
| Музыка/посты/товары/опросы/истории/другое | Ссылка и тип вложения |

Бот сначала скачивает доступный медиафайл во временное хранилище и загружает его в Telegram (до 45 МБ на файл), затем временные данные очищаются. Приватные/закрытые видео, файлы без прямого URL и вложения размером более 45 МБ пересылаются ссылкой; изредка URL может быть недоступен без авторизации VK. Универсальной пересылки «один в один» всех VK-форматов нет.

**Примечание:** программа не реализует отправку ответа *из Telegram* обратно в VK — кнопка открывает сам VK для ответа.

## Если ошибка доступа

- `VK messages.getLongPollServer: ошибка 7/15/20` — у приложения или токена нет разрешения читать личную переписку. Токен сообщества здесь не поможет.
- `Telegram sendMessage: chat not found` — напишите боту `/start` и проверьте `TG_CHAT_ID`.
- `Telegram ... wrong file identifier/failed to get HTTP URL content` — файл недоступен Telegram; должна прийти ссылка вместо файла.
- Работа остановится при закрытии консоли. Для 24/7 нужен непрерывно работающий компьютер или сервер.

Никогда не публикуйте свой `.env` и не присылайте токены посторонним. Если токен утёк, отзовите его и создайте новый.

## Проверка кода

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Тесты проверяют построение ссылок, отображение отправителей, экранирование текста, повторную отправку и выбор вложений. Тесты не заменяют проверку с **вашим** действующим VK API-токеном.
