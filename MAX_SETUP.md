# MAX + ВКонтакте → один Telegram-бот (тестовая ветка)

Этот вариант подключает НЕОФИЦИАЛЬНЫЙ клиент MAX из [Aist/max2tg](https://github.com/Aist/max2tg) к действующему VK/Gmail-боту. Есть риск ограничений аккаунта MAX; публичный API личных сообщений здесь не используется.

## Как устроено
- `gmail_bot.py` принимает почтовые уведомления VK и единственный читает `getUpdates` Telegram.
- `max2tg` подключается к личному MAX через WebSocket и отправляет в **тот же** Telegram-чат. `REPLY_ENABLED=false` принудительно: обратная отправка из Telegram пока отключена.
- `run_combined.py` управляет двумя независимыми процессами; после ошибок запускает их повторно.
- Версия MAX-клиента строго закреплена за коммитом `4f95ff962f797bbea5cc8461384208d148e1d039` (14.10.2026). Новые изменения автора автоматически не подтягиваются.

## Получение данных сессии MAX — только на своём компьютере
1. Перейдите на `https://web.max.ru/` и авторизуйтесь своим аккаунтом.
2. Откройте инструменты разработчика браузера: F12 → Application (Приложение) → Local Storage → `https://web.max.ru`.
3. Найдите `__oneme_auth`: это JSON. В переменную `MAX_TOKEN` помещается **только значение поля token**, без JSON целиком.
4. Найдите `__oneme_device_id`: значение поместите в `MAX_DEVICE_ID`.
5. Не отправляйте эти значения в чат, на скриншотах или в GitHub. Они дают доступ к аккаунту MAX. Не используйте `DEBUG=true`.

## Подготовка Bothost
ВНИМАНИЕ: не меняйте действующий бот до проверки этой ветки. Создайте резервную копию текущей конфигурации и SQLite.

1. Для существующего бота оставьте Git URL: `https://github.com/Joster13/vk-telegram-notifier.git`.
2. В настройках ветки укажите `feature/max-notifications-staging` вместо `main` **только когда будете готовы переключить развёртывание**.
3. Включите галочку **«Использовать собственный Dockerfile»**.
4. Домен выключен (не нужен), версия в Dockerfile — Python 3.12, точка входа задаётся его `CMD`. Поле «Главный файл» можно оставить пустым.
5. Сохраните переменные Gmail и Telegram из предыдущего деплоя и добавьте:
   - `MAX_TOKEN` — секретный токен вашей веб-сессии MAX;
   - `MAX_DEVICE_ID` — ID устройства MAX;
   - `DB_FILE=/app/data/vk_mail_state.sqlite3` (только после миграции существующей БД; см. ниже);
   - `REPLY_ENABLED=false`;
   - `DEBUG=false`.
6. Перед сменой версии перенесите текущий `vk_mail_state.sqlite3` в `/app/data/vk_mail_state.sqlite3` через файловый менеджер/терминал Bothost, если этот файл существует. Иначе часть ранее непересланных писем может быть пропущена. Скрипт попробует скопировать старую БД автоматически, если она всё ещё доступна в корне контейнера.
7. Разверните новую ветку. В Telegram должно прийти сообщение о запуске VK Notify, затем при авторизации MAX — уведомление `Max: подключён`.
8. Проверьте: `/test`, `/status`, новое письмо VK и новое личное сообщение MAX. У MAX ответы через Telegram пока не работают.

## Безопасность и ограничение функционала
- MAX автоматически возвращается к работе после разрывов WebSocket; возможна блокировка или принудительное завершение сессии.
- Токены хранятся только в переменных среды Bothost, не в Git.
- Установленный MAX-клиент — сторонний код, который получает доступ к вашей переписке.
- Входящие MAX могут содержать сообщения, вложения и данные контактов. **Временные логи MAX** находятся в контейнере `/tmp/max2tg-logs`, а стандартный вывод MAX скрыт от журнала Bothost: upstream-код иначе логирует фрагменты сообщений.
- В Gmail-версии всё ещё есть обнаруженные аудитом ограничения парсера и проверки писем. Этот этап их не изменяет.
- Не запускайте два экземпляра `gmail_bot.py` с одним токеном Telegram: getUpdates начнёт конфликтовать.

## Откат
Выберите в Bothost предыдущую ветку `main`, выключите использование собственного Dockerfile и установите главный файл `gmail_bot.py`. Выполните повторное развёртывание. Не удаляйте `/app/data` и не публикуйте содержимое `.env`.

## Лицензия и источник
Исходники `Aist/max2tg` не копируются в ваш GitHub, а скачиваются из указанного репозитория при Docker-сборке. Убедитесь, что такой способ использования соответствует правилам MAX и условиям автора. Репозиторий не заменяет официальное приложение MAX.
